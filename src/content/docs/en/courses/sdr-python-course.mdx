Wireless communications have become an indispensable part of our lives — but how does it all actually work? This hands-on course lets you experience it first-hand using **Software Defined Radio (SDR)** and **Python**, working with real-world signals in a practical, engaging environment.

<Aside type="tip">
  No prior RF experience needed. Basic programming knowledge and general Python familiarity are sufficient to get started.
</Aside>

## What You Will Learn

By the end of this course, attendees will have a solid intuitive understanding of:

- **DSP fundamentals** — sampling, aliasing, digital filtering, multirate signal processing, frequency domain concepts
- **SDR concepts** — architectures, RTL-SDR hardware, general-purpose SDR applications
- **Analog modulation** — AM, NBFM, WBFM demodulation including stereo, RDS, and subchannels
- **Digital modulation** — QPSK, constellation diagrams, pulse shaping, synchronization, decoding
- **ADS-B decoding** — extracting flight number, altitude, position, and speed from aircraft signals
- **GNU Radio** — flowgraph creation, blocks, data types, scheduler
- **Python DSP libraries** — NumPy, SciPy, Matplotlib, IQ file formats, spectrum monitoring

## Target Audience

This course is designed for engineers, professionals, students, and academics interested in signal processing or wireless communications. Whether you are new to the field or an experienced DSP engineer looking for a fresh, practical perspective — this course offers immediate, applicable value.

## Course Format & Materials

All hardware (RTL-SDR) is provided. Materials include:

- Jupyter Notebooks
- GNU Radio flowgraphs
- Slides and walkthrough examples
- IQ recordings
- Capture The Signal (CTS) sessions
